# Modelo de solicitud en aplicaciones PHP
En aplicaciones PHP, entradas HTTP pueden llegar por query string, cuerpo, cookies, cabeceras y estado de sesión. La ubicación de una entrada y su transformación deben observarse en el recurso actual; conocer PHP no demuestra que una entrada alcance un intérprete ni que exista una vulnerabilidad.
