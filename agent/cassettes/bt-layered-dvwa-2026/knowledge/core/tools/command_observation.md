# Interpretación de ejecución de comandos
El código de retorno, stdout, stderr, tiempo de espera y cambios observables deben analizarse en conjunto. Una ejecución exitosa no implica una hipótesis confirmada; un error de herramienta tampoco implica que el recurso sea seguro.
