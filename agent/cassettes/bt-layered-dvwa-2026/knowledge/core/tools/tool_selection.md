# Selección de herramientas por necesidad de evidencia
Las herramientas son capacidades, no pasos obligatorios. La elección debe responder a la información que falta: estructura HTTP, comportamiento diferencial, estado de sesión, contenido, interacción de navegador o confirmación independiente.
