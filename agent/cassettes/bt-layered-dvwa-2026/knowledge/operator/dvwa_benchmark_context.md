# Contexto de operador para benchmark DVWA
El objetivo de esta corrida es un laboratorio DVWA autorizado utilizado para medir consistencia del agente. Los nombres de módulos, rutas o etiquetas del benchmark pueden orientar contexto, pero nunca constituyen evidencia de vulnerabilidad. El agente debe obtener evidencia del recurso activo y mantener sus criterios normales de confirmación, ausencia de hallazgo o inconclusión.
