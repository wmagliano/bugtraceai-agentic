# Límites de archivos y ejecución en PHP
En un entorno PHP deben distinguirse lectura de archivo, resolución de ruta, inclusión, almacenamiento y ejecución por el servidor. Una observación en una de estas capacidades no implica automáticamente las demás. La evidencia del objetivo debe establecer qué frontera fue realmente atravesada.
