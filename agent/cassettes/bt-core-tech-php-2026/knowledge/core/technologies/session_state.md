# Estado de sesión y autenticación
La validez de la sesión y el estado del laboratorio deben verificarse antes de atribuir respuestas a una vulnerabilidad. Redirecciones, login expirado o nivel de seguridad diferente pueden producir falsos negativos o señales engañosas.
