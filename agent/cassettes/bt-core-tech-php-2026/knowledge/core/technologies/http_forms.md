# Formularios y solicitudes HTTP
Método, parámetros, codificación, cookies, redirecciones, tokens y contenido de respuesta forman parte del contexto tecnológico. Cambios pequeños entre solicitudes pueden explicar diferencias que no pertenecen a la hipótesis principal.
