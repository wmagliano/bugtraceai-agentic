# Separación entre conocimiento y evidencia
El conocimiento recuperado explica posibilidades generales. Solo las observaciones obtenidas del objetivo actual pueden sostener un veredicto. Una expectativa del laboratorio, una etiqueta de recurso o una descripción del RAG nunca confirman vulnerabilidad.
