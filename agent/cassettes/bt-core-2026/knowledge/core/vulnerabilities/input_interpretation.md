# Interpretación insegura de entradas
Varias clases de vulnerabilidad aparecen cuando una entrada controla la sintaxis de un intérprete. El análisis debe determinar qué componente interpreta la entrada, qué transformación ocurre y qué observación distinguiría datos de instrucciones.
