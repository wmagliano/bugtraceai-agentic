# Evidencia diferencial y controles
Una señal es más fuerte cuando existe una línea base comparable y una variación controlada. Deben aislarse cambios de estado, longitud, contenido, tiempo o comportamiento y evitar atribuir diferencias irrelevantes a la hipótesis.
