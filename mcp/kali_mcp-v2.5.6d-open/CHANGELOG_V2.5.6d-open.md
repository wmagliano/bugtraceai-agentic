# Kali MCP v2.5.6d-open

Base exacta: v2.5.6d proporcionada por el usuario.

Cambios experimentales:
- elimina allowlist de binarios en /tools/exec;
- acepta sintaxis Bash normal;
- mantiene scope de URL/IP al target configurado;
- conserva un denylist mínimo de operaciones destructivas sobre Kali;
- conserva el flujo de login/session de v2.5.6d;
- tolera URL pegada accidentalmente en formato Markdown;
- el instalador repara ownership de /tmp/bugtraceai-session y artifacts.

Sin payloads ni reglas específicas de vulnerabilidades.
