# Contributing

BugTraceAI is an Alpha scientific research project. Contributions are most useful when they preserve reproducibility and separation between reasoning, configuration, contextual knowledge and execution.

Useful contributions include reproducible bug reports, contract/state-machine corrections, documentation of experimental assumptions, tests for existing behavior, and target-general abstractions supported by evidence.

Please avoid silently embedding target-specific playbooks into the core Reasoner, presenting a new target as supported from one successful run, committing runtime cookies/logs/private credentials, or weakening scope and destructive-operation controls for convenience.

For architectural changes, describe the observed limitation, experimental condition, expected generalization and how the change can be evaluated independently.
